# Results Explorer Home Theme And Responsive Density Verification

Date: 2026-05-12
Branch: `fix/results-explorer-home-theme-density`

## Contract Decision

- Home keeps the mixed Results Explorer contract: dark hero/chrome/filter shell, light analytical data surface.
- The corpus-summary region remains, but the copy contract is current leaderboard-scope language, not legacy `PR-validated corpus`.
- Mobile keeps the existing first-leaderboard-row budget: first row y <= 1200 at 390x900.
- Desktop/wide keep the first-row-in-viewport budget and require comparison to start above the fold. The stale "all fixture rows above fold" assertion was replaced with a documented minimum of two visible rows because the product identity, active filters, cohort selector, and table controls intentionally precede the grid.

## Baseline Evidence

Raw browser measurements: `/tmp/results-explorer-home-theme-density-baseline.json`.

- Home smoke failed because `PR-validated corpus` was not present in `Corpus summary`.
- Responsive home smoke failed on mobile: first leaderboard row y was 1432.38 against the 1200 budget.
- Baseline theme tokens were already mixed by design:
  - hero/filter shell `rgb(13, 17, 23)` / `rgb(22, 27, 34)`;
  - data surface `rgb(245, 246, 248)`;
  - body `rgb(245, 246, 248)`.
- Mobile selector height was 479.38 px, mostly from always-expanded scope explanation and mobile-visible helper copy.

## Implementation Summary

- Kept the mixed dark/light theme and encoded it with `data-surface="hero"` and `data-surface="app"`.
- Collapsed the verbose leaderboard-scope explanation behind mobile-only `Leaderboard scope details`.
- Hid nonessential select helper copy on mobile while preserving benchmark, scale, phase, advanced filters, and Compare controls.
- Updated home smoke to expect `leaderboard cohorts` and assert absence of `PR-validated corpus`.
- Updated responsive desktop row-count budget to the documented "comparison starts above the fold" contract.

## Browser Evidence

Raw post-change measurements: `/tmp/results-explorer-home-theme-density-after.json`.

- Mobile first leaderboard row y: 1147 <= 1200.
- Tablet first leaderboard row y: 1081.25 <= 1200.
- Desktop first leaderboard row y: 833.25 <= 900.
- Mobile `Leaderboard scope details` is visible and closed by default.
- Hero/data surfaces retain distinct theme tokens: hero `rgb(13, 17, 23)`, data `rgb(245, 246, 248)`.
