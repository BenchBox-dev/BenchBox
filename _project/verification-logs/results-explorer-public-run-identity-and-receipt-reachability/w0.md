# Results Explorer Public Run Identity Verification

Date: 2026-05-12
Branch: `fix/results-explorer-public-run-identity`

## Contract Decision

- `result_id` is the canonical public result identity and result-detail route target.
- `short_id` remains a compare URL transport alias when a surface has it available.
- Visible run identity uses `Public ID <token derived from result_id>`, never a bare compare URL alias.
- Origin context such as `(from result detail)` is rendered as a separate status chip, not appended to the platform name.
