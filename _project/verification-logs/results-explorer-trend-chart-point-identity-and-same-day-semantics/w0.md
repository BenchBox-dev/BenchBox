## W1 Decision

Duplicate-day policy: suppress the line chart when a TimeSeries cohort contains multiple trendable rows for the same `platform_id` and `run_date`.

Rationale:

- The read model only carries `run_date`, not a timestamp or deterministic within-day sequence.
- Drawing a line through same-day points implies an ordering the data does not provide.
- Aggregation would require a product policy such as latest, median, or best valid run; none is encoded in the current read model.
- Suppression preserves the data contract while still exposing the underlying run links for inspection.

Chosen display: a compact duplicate-day state with date, platform, public ID, metric value, details link, and receipt link for each duplicate run.
