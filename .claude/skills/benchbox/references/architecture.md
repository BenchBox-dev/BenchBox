# Architecture Review Reference

Review BenchBox structure at module boundaries, not style preference.

## Axes

- Adapter responsibilities and lazy optional imports.
- SQL compatibility rules vs adapter-local rewrites.
- Benchmark/query/dataframe layout consistency.
- Validation, timing, logging, and artifact boundaries.
- Duplication worth standardizing without over-abstracting.
- Compatibility with current release/dev-loop workflow.

## Output

Findings by severity with file evidence, tradeoffs, rejected alternatives, and concrete follow-up tests/docs.
