# Benchmark Compare Reference

Compare implementations for semantic parity and useful standardization.

## Axes

- Query count/names/order and parameter behavior.
- Schema/load/generation conventions.
- Validation mode and result-shape compatibility.
- Platform options and phase propagation.
- Tests, docs, and failure reporting.

## Output

Matrix shared/different/missing, risks by severity, and recommendation: standardize, preserve platform-specific behavior, or defer.
