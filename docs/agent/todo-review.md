# TODO review: own-edit-target freshness

Companion to `.claude/skills/todo-db/references/review.md`. This file is
not part of the active instruction-byte surface.

When a TODO's `only_modify` includes a living policy, spec, or goal document
and the description quotes that document, require a `w0` that re-reads current
text and diffs it against the quoted claims. Line-number citations are not
durable evidence. Score evidence durability 0 if that re-read is absent.

This is own-edit-target freshness. It is not
`todo-review-semantic-guardrails`.
